Autorizar acesso remoto

Um técnico solicitou acesso remoto ao seu computador para resolver um problema.

Ao autorizar, você concorda que o técnico possa acessar esta máquina nesta sessão. O acesso é temporário e fica registrado (data, hora e endereço IP) para sua segurança.

Acesso autorizado

Autorização registrada. Abaixo o que o técnico já recebeu — você não precisa copiar nada.
Baixar ferramenta de acesso (Windows)

1. Execute o arquivo baixado e clique em Sim quando o Windows pedir permissão.
2. Já tem o RustDesk instalado? O script detecta e pula a instalação — vai direto para a configuração.
3. O script aplica a senha de atendimento e envia o seu código de acesso ao técnico automaticamente — você não precisa digitar nem copiar nada.
4. Mantenha o RustDesk aberto até o fim do atendimento.
5. Ao final, clique em "Encerrar atendimento" abaixo para revogar o acesso remoto.

Encerrar atendimento (revogar acesso)

Vai usar acesso remoto de novo? Use o botão acima: ele revoga o acesso e mantém o RustDesk instalado (o próximo atendimento é mais rápido).
Não vai usar mais? Use o botão abaixo para desinstalar o RustDesk por completo.
